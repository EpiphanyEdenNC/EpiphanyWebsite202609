# Epiphany Website — setup checklist

## Local
- [ ] Install Node.js LTS
- [ ] Open project folder in VS Code
- [ ] Run `npm install`
- [ ] Run `npm run dev`
- [ ] Check homepage and mobile menu
- [ ] Open `/admin/index.html`

## GitHub
- [ ] Initialize repository from VS Code Source Control
- [ ] Make first commit
- [ ] Publish to GitHub as a private repository

## TinaCloud
- [ ] Import GitHub repository into TinaCloud
- [ ] Add first two editors
- [ ] Copy Client ID and token
- [ ] Add local `.env`

## Netlify
- [ ] Import repository
- [ ] Confirm build command `npm run build`
- [ ] Confirm publish folder `dist`
- [ ] Add Tina environment variables (`PUBLIC_TINA_CLIENT_ID`, `TINA_TOKEN`)
- [ ] Add `SITE_URL`
- [ ] Deploy

## Before launch
- [ ] Add full address
- [ ] Add parish email and phone
- [ ] Add Facebook and YouTube links
- [ ] Add Tithely donation link
- [ ] Add Mailchimp signup link
- [ ] Upload real parish photos
- [ ] Replace sample events
- [ ] Verify worship time
- [ ] Test every page on phone and desktop
- [ ] Test `/admin/index.html` with both editors
- [ ] Connect custom domain only after the temporary Netlify URL is approved
